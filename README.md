
# FLIM Lifetime Fitting Application

This repository contains a complete Fluorescence Lifetime Imaging (FLIM) software suite developed in Python. It includes:

- **Live Measurement Interface** for PicoQuant PicoHarp 300
- **Lifetime Fitting GUI** using time-resolved decay data
- Integrated IRF convolution and real-time fitting using the Powell method
- Export functionality for decay curves and fitting results

## 📁 Files Included

| File | Description |
|------|-------------|
| `FLIM_mainscript.py` | Full application script for live measurement and lifetime fitting |
| `example_decay_data.xlsx` | Sample decay data (time vs. counts) for testing the fitting interface |
| `example_irf.xlsx` | Sample instrument response function (IRF) file for testing convolution fitting |
| `example_csv_output.xlsx` | Example of the output generated by the `Save Fit Data` option in the GUI |

---

## ▶️ How to Run

1. Make sure you have Python 3 installed, along with the required libraries:
    ```bash
    pip install numpy pandas matplotlib scipy
    ```

2. Run the software from the command line:
    ```bash
    python FLIM_mainscript.py
    ```

3. Use the **Lifetime Fitting** tab to:
    - Upload the included example IRF and decay data
    - Set your ROI and fit range
    - Fit the data and save plots or results

---

## 🧪 Example Data

To test the software without hardware:

- Load `example_irf.xlsx` as your IRF
- Load `example_decay_data.xlsx` as your observed signal
- Specify an ROI (e.g., 0 to 30 ns), and fitting range (start = 80% of rising edge, stop = 1% of falling edge)
- Click **Run Fitting** to perform convolutional fitting with the IRF

Output can be saved using **Save Plot** and **Save CSV** buttons.

---

## 📤 Output Format

The exported `.csv` contains the following columns:

- Time (ns)
- Observed Counts
- IRF Used
- Fitted Counts
- Tau (ns)
- Shift (ns)
- Reduced χ²

---

## ℹ️ Notes

- IRF and signal data must be in **CSV format** with columns named `Time (ns)` and `Counts`.
- This software supports **live acquisition** using the PicoQuant PHLib driver. Ensure `phlib64.dll` is available in the working directory when using the PicoHarp tab.
